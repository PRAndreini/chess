CHESS-FROM-SCRATCH PACKAGE README:

To use this code:

0. Ensure that you have Python3 installed on your system.
    - The latest version is always best. This code was written using v. 3.13.0 (although there shouldn't be a problem with using an earlier version of Python3).
1. Download the Python scripts "ChessEngine.py" and "ChessMain.py".
2. Download from the chess piece .png files.
3. Put the chess piece .png files in a folder called "pieces" (case-sensitive!).

Troubleshooting: sometimes, you need to edit "ChessMain.py" to add/remove the charcaters "chess/" from the function "load_piece_images()" in "ChessMain.py" at line 51.

MOST IMPORTANT: DO NOT FORGET!
    Have fun!
