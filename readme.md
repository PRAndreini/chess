CHESS-FROM-SCRATCH PACKAGE README:

To use this code:

0. Ensure that you have Python3 installed on your system.
    - The latest version is always best. This code was written using v. 3.13.0 (although there shouldn't be a problem with using an earlier version of Python3).
1. Choose a local directory for the files necessary to run the game; name it something like "chess" (name does not matter).
2. Download the Python scripts "ChessEngine.py" and "ChessMain.py"; move these into "chess".
3. Download from the chess piece .png files; put all of these in a sub-directory called "pieces" inside of "chess" (the name "pieces" DOES matter; copy it exactly, all lower-case).
4. To play the game, either run in Terminal "python ChessMain.py", or choose your preferred method of running Python3 scripts.

MOST IMPORTANT: DO NOT FORGET!
    Have fun!
